Roles Check · HTTP 403

Every action appends to a SHA-256 hash-chained audit log with actor, timestamp, amounts, and state. Each row includes the hash of the previous row. Tamper with any entry and verification shows exactly where the chain breaks. Try it in the Live Engine.

Simulated: Afterglow Labs (fictional AV touring company), Chase/PayPal/Ramp transaction data, September 2026 scenario, Maya's Steam purchase, EUR crew deposit.

Real code: Single ledger gateway (only write path), role-based authorization (HTTP 403), state machine (new → proposed → needs_info → approved → posted), SHA-256 hash-chained audit log, challenge/defend/concede with precedent recording.

Built with Cursor (Claude Sonnet 4.5) and Grok Bot during Cal Hacks 2026. The showcase uses TypeScript + Three.js + GSAP for the frontend demos. The full Python backend (state machine, audit log, challenge system) lives in the GitHub repo.
